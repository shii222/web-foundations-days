
# Day 8 — Course Reflection

## 1. What Was the Most Difficult Concept, and How Did I Overcome It?

The most difficult concept for me was understanding system architecture and how different components work together. At first, I found it challenging to understand the relationship between APIs, databases, caching, load balancers, and application servers. I also struggled with understanding how database transactions prevent two users from purchasing the same seat.

I overcame these challenges by practicing step by step, reviewing examples, and applying the concepts to projects such as QuickNotes and TicketHub. Building diagrams and calculating traffic helped me understand why each component is necessary.

## 2. Which Part of My Capstone Would I Improve?

In my QuickNotes capstone, I received 83/100. The feedback highlighted missing or incomplete architecture documentation and a small JavaScript bug in the empty-state handling.

I improved my JavaScript by adding the missing data-empty attribute so the placeholder disappears when a note is created. I also revised my architecture document to explain the POST request flow, system trade-offs, and how the application handles component failures.

This experience taught me the importance of testing, reviewing documentation, and responding to feedback.

## 3. What Will I Learn Next?

My next goal is to strengthen my JavaScript, Python, SQL, and backend development skills. I want to learn how to build complete applications that connect frontend interfaces to real databases through REST APIs.

I also plan to improve my Git and GitHub skills and continue building practical projects that solve real-world problems.
